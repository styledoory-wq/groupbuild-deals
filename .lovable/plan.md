# רשימת דפים לבנייה (לפי הסדר)

## ✅ הושלמו
- דף בית / לוח שכנים
- רשימת עסקאות
- דף עסקה בודדת (Deal Detail)
- תשלום / הצטרפות לעסקה (Checkout)
- פרופיל ספק (Supplier Profile)
- רשימת קטגוריות (Categories)
- דף הצעת עסקה חדשה / עריכה (Offer Editor)
- העסקאות שלי (My Offers)
- התראות (Notifications)
- פרופיל משתמש / הגדרות (Resident Profile)
- דשבורד ספק (Supplier Dashboard)
- דשבורד אדמין (Admin Dashboard)
- אונבורדינג + הרשמה/התחברות (Welcome + Auth)
- עמודים נוספים: שכפול, מועדפים, חיפוש, תקציב, מסמכים, פיקדונות, ואוכרים, ועוד

## ⏳ נותר לשיפור / בנייה
1. ~~**דף ועד בית**~~ ✅ — דשבורד נציגי ועד בית + בקשת הרשאה + ניהול בקשות באדמין
2. **שיפור UI/UX קיים** — שיפור דפים קיימים, ניקוי, אחידות
3. **מסכי אנליטיקס / סטטיסטיקות** — לספקים ולמערכת
4. **כרטיסיות / דפי שיווק** — עמודי נחיתה לעסקאות ספציפיות
5. **תכונות חדשות** — לפי צורך עסקי

> רוב הדפים המרכזיים כבר קיימים ופועלים. השלב הבא יכול להיות שיפור, ניקוי ואחידות UI, או תכונה חדשה ספציפית.
