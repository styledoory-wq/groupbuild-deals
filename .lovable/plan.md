# תיקונים בעמוד הצעה (Deal Detail) + עורך הצעות

## 1. תיקון חישוב "הקבוצה חסכה יחד"
כיום הנוסחה: `(referencePrice − currentEffectivePrice) × participantCount` — יוצרת חיסכון מדומה כשמחיר רגיל גבוה ממדרגה ראשונה.

**חדש:** השוואה מול מחיר המדרגה הראשונה (1-1).
- עם 1 משתתף במדרגה 1-1 → חיסכון 0
- ברגע שמדרגה 2-3 נפתחת ב-5,500 → 200 × 2 = 400 ₪
- אם הכרטיס מציג 0 — נסתיר אותו לגמרי (לא להציג "0 ₪")

## 2. הסטפר האופקי יתחיל מהמדרגה הראשונה
כיום: כשאף אחד לא הצטרף, חלון המדרגות ממורכז והמדרגה האמצעית מובלטת.
**חדש:** כשהמדרגה הפעילה היא הראשונה (1-1), חלון התצוגה יתחיל ממנה ויראה את 3 המדרגות הראשונות — המסגרת המובלטת תהיה הראשונה מימין.

## 3. הוספת "פירוט מוצר"
בעמוד ההצעה, מתחת לכותרת/תיאור — מקטע חדש "פירוט מוצר" שמרכז: מה כלול, מפרט, גודל/כמות, מותג, אחריות וכו'. אם הספק לא מילא — לא יוצג.

בעורך ההצעה (שלב 1 – פרטים בסיסיים): להוסיף שדה טקסט אופציונלי "פירוט מוצר" (textarea), נשמר בעמודה חדשה `product_details` בטבלת `offers`.

## 4. אפשרות מדרגה החל מ-1 (יחידה בודדת)
כיום עורך ההצעה כפה שמדרגה ראשונה תתחיל מ-2 (כי "קבוצת רכישה היא מ-2").

**חדש:** לאפשר לספק להתחיל ממדרגה 1 — כלומר לתת הנחה כבר לרוכש הראשון. הוולידציה תרשה `min_quantity ≥ 1`. אם המדרגה הראשונה היא 1, התווית בסטפר תהיה "1 רוכש" במקום "1-1 מצטרפים".
