# אבחון: GroupBuild לא זמינה (ללא שינויים)

## ממצאים מאומתים
1. **מסד הנתונים מושהה (Paused).** בדיקת סטטוס Lovable Cloud של הפרויקט מחזירה: "backend is paused" — מסד נתונים והתחברות לא פועלים.
2. **השרת לא עונה בכלל.** קריאה ישירה לכתובת השרת (נתונים והתחברות) לא קיבלה תשובה (קוד 000), בעוד שהאתר עצמו groupbuild.co.il עולה (200).
3. **הפרויקט אכן על Lovable Cloud** (שרת אחד משרת גם את התצוגה המקדימה וגם את האתר המפורסם).
4. **יש קרדיטים כעת:** יתרה 249.38 (200 חודשיים + 49.28 rollover, שיפוג ב-28.11). מכסה זו מאפשרת הערה מחדש.

## גורם שורש
האתר המפורסם (העיצוב/המסכים) מוגש בנפרד ופועל, אבל השרת מושהה — ולכן: אין טעינת עסקים, אין התחברות/הרשמה, ומסכים שתלויים בנתונים נכשלים. "enabled:true" רק מציין שהשירות מוגדר, לא שהוא פעיל. ההשהיה תואמת למיילים מספטמבר על חוסר קרדיטים; לא ניתן לאמת מכאן את תאריך ההשהיה או את סיבתה המדויקת (השהיה בשל קרדיטים או ידנית).

## שחזור ללא מחיקת נתונים
1. בפרויקט: More → Database → Manage → Settings → **Wake up / Resume** (או לבקש ממני להעיר — דורש אישורך).
2. להמתין כמה דקות עד שהסטטוס יהיה פעיל.
3. לבדוק: טעינת עסקים, התחברות, הרשמה באתר החי.
4. השהיה לא מוחקת נתונים; ההערה מחזירה את המצב הקיים.
5. מומלץ להגדיר התראת יתרה נמוכה / טעינה אוטומטית ב-Workspace settings → Usage limits & alerts.

## מה חסר לבדיקה
- תאריך וסיבת ההשהיה (קרדיטים מול ידנית).
- תקינות הנתונים והתחברות אחרי ההערה (אפשר רק כשהשרת פעיל).
