# resources/residents

Drop the following files here before running `APP_PROFILE=residents npm run app:sync`:

- `icon.png` — 1024×1024, opaque
- `splash.png` — 2732×2732, opaque, brand color `#F7F5F0`
- `google-services.json` — from Firebase console (Android push)
- `GoogleService-Info.plist` — optional (iOS Firebase features)

These files are consumed ONLY by the `residents` profile.
